# Personal Expense Tracker

## Project Description
Personal Expense Tracker is a Python-based desktop application developed to help users manage their daily expenses and monitor their monthly budget.

## Technologies Used
- Python
- Tkinter (GUI)
- CSV (Data Storage)
- Matplotlib (Data Visualization)

## Features
- Add and delete expenses
- Search expenses
- Automatic date tracking
- Store expense records using CSV
- Calculate monthly expenses
- Monitor remaining budget
- Budget warning notifications
- Pie Chart for category-wise expenses
- Bar Chart for monthly expense analysis

## Purpose
The main purpose of this project is to help users track their spending habits, manage their budget and understand their expenses through graphical reports.

## How to Run
1. Install Python.
2. Install Matplotlib using:
   `pip install matplotlib`
3. Run the Python file:
   `python "expense tracker.py"`
